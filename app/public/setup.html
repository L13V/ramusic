Spotify app credentials

Create (or open) an app in the Spotify Developer Dashboard, add this exact Redirect URI to its settings, then paste its Client ID here.

This URI never changes. It's a fixed localhost address the sign-in uses on the TV, so you add it once and never touch it again — even after restarts. (Settings → Redirect URIs → Add → Save.)

Not required — sign-in uses PKCE. Only fill this if you already use a secret.
